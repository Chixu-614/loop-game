# 循环·密室逃脱

一款多周目解谜网页游戏。

## 简介

这是一个多周目循环解谜游戏——你被困在一间密室里，需要通过观察、收集线索、解谜来逃出。但事情没有这么简单，每次"逃出"后，你会发现自己又回到了起点……

## 玩法

- 点击房间内的物品（门、窗户、镜子、纸条、锁）进行交互
- 收集线索，解开密码锁
- 多周目循环，每一轮都有新的发现

## 游玩

直接打开 `index.html` 即可游玩，或访问 GitHub Pages 在线版。

## 技术栈

纯前端实现：HTML + CSS + JavaScript，无需服务器，无需依赖。
